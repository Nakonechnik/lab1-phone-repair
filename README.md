# Phone Repair - заявка на ремонт смартфона

**ФИО:** Крутов Артём Викторович  
**Группа:** Б9124-02.03.01сцт

## Предметная область

Приложение моделирует заявки в сервисном центре по ремонту смартфонов. У заявки есть состояния: новая, диагностика, ожидание запчастей, ремонт, готов к выдаче, выдан, отклонён. Переходы между ними разрешены только по правилам: например, ремонт нельзя начать, пока одновременно не выполнены диагностика, наличие запчастей, согласие клиента и оплата (либо гарантия). Сложность повреждения влияет на смету и на то, нужны ли запчасти со склада. В особых состояниях экран и строка списка меняют цвет. Заявку можно сбросить в исходное состояние.

Правила переходов со первого задания не менялись. После диагностики заявка уходит в ожидание запчастей только если их нет на складе.

## Экраны

1. Список заявок - не меньше десяти объектов при запуске, видно состояние каждой, особые статусы выделены цветом. Можно добавлять и удалять заявки.
2. Карточка заявки - все действия из первого задания. Состояние у каждой заявки своё; изменения видны в списке после возврата.

Состояние хранится во ViewModel и репозитории (UDF). Навигация на Navigation 3. Данные переживают поворот экрана, между запусками приложения не сохраняются.

## Как запустить

1. Открыть проект в Android Studio.
2. Дождаться синхронизации Gradle.
3. Запустить на эмуляторе или устройстве.
